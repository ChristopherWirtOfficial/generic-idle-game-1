# History: v1, v2, and the failure pattern

## v1 — "the wireframe that shipped" (rejected)

First build: spec-sheet aesthetic. Engineering-drawing title block, paper
white, dot grid, THE BUTTON, 8 generators (Point Maker → Point Singularity),
deadpan copy ("You are no longer needed."), achievements, prestige, offline
progress. Technically complete, tested, shipped.

Christopher's verdict, near-verbatim: the aesthetic conceit is "better on
paper than on page… just too boring, kind of by design, and I don't like
that design." Also: gameplay bland. He proposed the chain concept here —
"generating points with only the bottom tier of generator and then each
generator above generates the one below it" — and, critically, the process
instruction that governs everything since: **"ignore my prescription and try
to find and hear my sentiments."**

## v2 — cosmic "living sky" chain rework (rejected)

Full from-scratch rework: chain production under a cosmic theme (stardust,
motes, condensation, "the void waits"). Fixed the boredom, lost the soul.

Christopher: "we've lost the conceit-less nature. It should still be raw to
the user but that doesn't mean the UI needs to be boring." He pointed at a
reference game (see 02) and asked to "talk for a while instead of blind
coding. Let's collaborate."

## The failure pattern (named, own it)

Three times running, Claude let the chrome write the content: spec-sheet
became a game *about* spec sheets, cosmos became a game about condensation,
and a dot-matrix pitch for v3 was about to clone the reference's clothes.
Christopher: "you often take a design UI theme and make the whole game it…
this game isn't dot matrix themed, despite having a coherent UI aesthetic."

The law extracted: **content gets zero conceit** (tiers are numbers 1–8,
currency is a bare score, no lore, no flavor nouns), **chrome gets a voice
but the voice never generates nouns**. The reference game's UI is
opinionated as hell and the game still isn't "about" anything.

## v3 — current build

Designed collaboratively in dialogue before any code (see 02–04), then
built from scratch: cycles, sculpted pool, additive tableau, rising ladder,
scenarios. The rest of these docs describe it.
