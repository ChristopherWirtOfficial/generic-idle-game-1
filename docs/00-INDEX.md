# Design docs — read me first

These docs exist because this project's context lived in a long chat with
Christopher that you (Claude Code) don't have. CLAUDE.md is the operating
summary; these are the full record — decisions WITH their reasoning, the
rejected paths WITH why they died, the open questions WITH their current
lean. When Christopher references "what we talked about," it's in here.

- **01-history.md** — v1 and v2, both rejected, and the failure pattern that
  produced the core design law.
- **02-ig1-research.md** — the reference game ("Idle Game 1" by cem) and
  Christopher's dissection of it. This is the taste document. Most v3
  decisions trace to a sentence in here.
- **03-decisions.md** — everything settled, each with rationale and the
  evolution that got it there.
- **04-rejected-and-open.md** — the graveyard and the parking lot: rejected
  ideas, deferred forks, waffles, uncertainties.
- **05-economy-and-sim.md** — tuning rationale, sim methodology, the three
  degeneracies the sim caught, current validated arc, what to re-run when.
- **06-ui-chrome.md** — the instrument skin: intent, anatomy, animation
  architecture, and the planned (not yet held) joint art-direction session.
- **07-process.md** — how this collaboration works: sentiment over
  prescription, stab-then-art-direct, honest-instrument standard, ship
  pipeline.

The single most important thing if you read nothing else: **raw content,
rich chrome — and chrome never generates nouns.** Two full builds died to
learn that. See 01.
